# Personal landing — Maksim Kozlov

English portfolio site: Next.js (App Router) · TypeScript · Tailwind CSS v4.

## Run

```bash
cd personal-landing
npm run dev
# http://localhost:3000
```

## Edit content

All copy lives in [`src/data/content.ts`](src/data/content.ts) — name, contacts, services, anonymized experience, skills.

**Privacy:** employer company names are intentionally omitted.

## Build

```bash
npm run build && npm start
```
